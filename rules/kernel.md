## vstack

For any change beyond a trivial edit, run `vstack start <feature|bugfix|refactor|investigate|spike> "<goal>" --size S|M|L`, do what it prints, and advance with `vstack done "<evidence>"`. Do not read ahead.

Always: data shape before logic. Smallest diff. Prove it on the real surface. Evidence, not claims. No narrating comments, type escapes, or swallowed errors. Ask only for decisions you cannot settle by running something.
